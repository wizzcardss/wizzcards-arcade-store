# WizzCards Arcade Store

Tienda estática con pantalla de bienvenida, catálogo por categoría, búsqueda, ordenamiento, carrito persistente y generación de pedido.

## Ejecutar localmente
Ejecuta `python3 -m http.server 8000` en esta carpeta y abre `http://localhost:8000`.

## Catálogo
Edita `catalog.json`. Precio expresado en CLP. Los ID WIYV enlazan con las fichas de Jira. El catálogo actual es una selección inicial, no una sincronización en vivo.

## Recursos visuales
- `assets/wizzcards-grok-splash.png`: pantalla de bienvenida aprobada.
- `assets/grok-mascot.png`: mascota para la sección principal.
